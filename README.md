## 我对 AI Agent 的理解

AI Agent 是一种可以根据目标自己思考、选择工具并完成任务的人工智能程序。它不只是回答问题，还可以根据当前情况一步一步执行操作，比如读取信息、分析问题、写代码、运行程序和修改错误。

我理解的 ReAct 是 Reason 和 Act 的结合，也就是先思考下一步要做什么，再采取行动，然后根据结果继续调整。这样的方式可以让 AI Agent 更像一个会解决问题的助手。
